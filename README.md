# DevFolio — Sandeep Kota

A responsive personal portfolio website built using HTML and CSS.

## Description

This portfolio showcases my introduction, projects and contact information.
The website uses semantic HTML, CSS Flexbox, CSS Grid and responsive design.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- GitHub Pages

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
